## Background

A prior 2-track flux-review of `hooks/session-start.sh` produced 52 findings,
17 P0. Synthesis identified 5 critical P0s:

- **CF-1** — pre-commit hook fails to reconcile cross-session staged state.
  Concurrent commits silently lose work. The cure is currently worse than the
  disease.
- **CF-2** — `stop.sh:25-27` reads `${GIT_INDEX_FILE:-}` but the wrapper never
  globally exports it. Every well-behaved session leaks. Root cause of 638
  orphan files in elf-revel; not crashes.
- **CF-3** — cwd-prefix string check still fires when cd'd into a nested .git
  dir. v0.2.13's flag-scan covers `git -C` but not nested cwd.
- **CF-4** — `GIT_DIR` / `GIT_WORK_TREE` env-var bypass. v0.2.13's flag-scan
  catches the flag form; env-var form smuggles past.
- **CF-5** — SessionStart-fires-twice TOCTOU on `[[ ! -f $SESSION_INDEX ]]`
  init guard.

Track C also surfaced one finding worth keeping foregrounded: orphan indexes
may contain the only copy of staged-but-uncommitted work. Cleanup must
classify-before-delete (mortuary chain-of-custody lens).

## Proposed ship sequence

### v0.2.14 — Lifecycle hotfix

**Files touched:**
- `hooks/stop.sh` — reconstruct SESSION_INDEX path from `$SESSION_ID` + `$GIT_ROOT` rather than relying on never-exported `GIT_INDEX_FILE`.
- `hooks/lib.sh` — add classify helper (`session_index_is_empty()`) and orphan path enumerator.
- `hooks/session-start.sh` — atomic init (write to `$SESSION_INDEX.tmp`, fsync, rename), `INTERLOCK_DISABLE_INDEX_ISOLATION=1` escape hatch at top of file.
- `scripts/interlock-orphan-sweep` — new TTL sweeper (>7 days → classify; empty → delete; non-empty → quarantine as `.git/index-<UUID>.abandoned-<timestamp>`).
- `.claude-plugin/plugin.json` — bump to 0.2.14.
- Tests as listed in step 5 of plan.

**Effect on a user who upgrades to v0.2.14 only (and doesn't reach v0.2.15):**
- Cleanup gap fixed.
- Nested-repo bug NOT fixed (still v0.2.13's cwd-prefix predicate).
- Concurrent-commit silent-data-loss NOT fixed.

### v0.2.15 — Wrapper hardening

**Files touched:**
- `hooks/session-start.sh`:
  - Per-call `command git rev-parse --show-toplevel` comparison to session-start `GIT_ROOT` (with env stripped: `env -u GIT_DIR -u GIT_WORK_TREE -u GIT_INDEX_FILE command git rev-parse ...`).
  - Use `--git-dir` for SESSION_INDEX path construction so linked worktrees don't break (their `.git` is a file pointing to a separate gitdir).
  - One-time stderr warning when zsh detected and `export -f` silently no-ops.
  - Strip `GIT_DIR`/`GIT_WORK_TREE` from env at the top of the wrapped function before any rev-parse runs.
- `.claude-plugin/plugin.json` — bump to 0.2.15.
